# 河南 · 开封美食地图

小红书帖子与评论区截图（62 张）逐条整理成的一份**可交互地图清单**——吃的、店名、位置、推荐菜、来源截图，一次看全。

## 🔗 在线访问

**https://qiling77755.github.io/henan-kaifeng/**

> 手机可直接打开，支持双指缩放地图；电脑端滚轮缩放 / 拖拽平移。

## 功能

| 功能 | 说明 |
|---|---|
| 217 条条目 | 店铺 / 摊位 / 景点 / 住宿，按街区与类型筛选、可搜索店名或菜品 |
| 坐标分级 | 精确定位 113 条（实心圆点）· 区域近似 70 条（空心虚线点）· 未定位 34 条 |
| 住宿标注 | 汉庭酒店(开封鼓楼火车站店)，全图**唯一的红色五角星** |
| 距离计算 | 「获取我的位置」按浏览器定位，或「以酒店为基准」，算球面直线距离（Haversine） |
| 可核对 | 每条都能点开**来源截图原图**，注明出处图号 |
| 一键复制 | 卡片店名旁的「复制」按钮复制店名；详情页可复制「名称 + 地址」 |

## 使用

**在线**：直接访问上面的链接。

**本地**：下载后双击 `index.html` 即可，零外部依赖——仅底图瓦片需要联网（来自高德）。瓦片加载失败时圆点与清单数据不受影响。

## 数据口径

- 坐标经**腾讯地图地点检索**（placeSuggestion）逐条比对，采用地图返回的 POI 经纬度；同品牌多分店时取与截图语境最匹配的分店。
- **未定位条目**多为夜市摊点、简称或帖主手写清单，未检索到唯一匹配结果，标注「待核实」，**不编造坐标**。
- 已合并 9 条重复条目（同一实体的泛称与具体分店）。
- 距离为**球面直线距离**，非驾车/步行路径距离，实际路程会更长。
